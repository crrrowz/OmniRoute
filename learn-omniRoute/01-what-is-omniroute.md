# 01 — شنو هو OmniRoute؟ (الفكرة والمصطلحات)

## 🤔 المشكلة اللي يحلها

تخيّل عندك:
- اشتراك Claude Pro، واشتراك ChatGPT Plus (Codex)،
- مفتاح API من Groq ومفتاح من DeepSeek،
- وتريد تستخدم مزودين مجانيين مثل Kiro أو Pollinations.

بدون OmniRoute: كل أداة (Cursor، Claude Code، Continue…) لازم تربطها بمزود واحد، وإذا خلصت
الحصة أو وگع المزود → توگف شغلك وتبدّل الإعدادات يدوياً.

**OmniRoute = راوتر (موجّه) ذكي يكعد بين أدواتك وبين كل مزودي الذكاء الاصطناعي.**

```
  أدواتك (Cursor, Claude Code, Codex, سكربتاتك...)
                 │
                 ▼   رابط واحد:  http://localhost:20128/v1
        ┌─────────────────────┐
        │      OmniRoute      │  ← يختار المزود، يحوّل الصيغة، يعيد المحاولة،
        │  (راوتر + لوحة تحكم) │    يضغط البرومبت، يحسب الكلفة، يسجّل كلشي
        └─────────────────────┘
          │       │       │       │
          ▼       ▼       ▼       ▼
       Claude   OpenAI  Gemini  Kiro (مجاني) ... (أكثر من 350 مزود)
```

## 💡 ليش مفيد؟ (الفوائد الكبيرة)

1. **رابط واحد لكل شي** — أدواتك تتكلم بصيغة OpenAI مع OmniRoute، وهو يترجم لصيغة Claude أو
   Gemini أو غيرها تلقائياً.
2. **Fallback تلقائي** — إذا المزود الأول فشل أو خلصت حصته، ينتقل للي بعده بدون ما تحس.
3. **دمج الطبقات المجانية** — تربط عدة مزودين مجانيين وتصير عندك سعة أكبر بكلفة صفر.
4. **الاستفادة الكاملة من اشتراكاتك** — يستهلك اشتراكك أولاً وبعدين ينتقل للأرخص.
5. **توفير التوكنز** — يضغط البرومبت قبل لا يوصل للمزود (بعض المحركات توفر 60–90% على مخرجات الأوامر).
6. **مراقبة كاملة** — كل طلب مسجّل: منو، شنو الموديل، كم توكن، كم كلّف، كم أخذ وقت.
7. **ميزات وكلاء** — سيرفر MCP، سيرفر A2A، ذاكرة، مهارات، وكلاء سحابيين.

## 📖 المصطلحات الأساسية (لازم تحفظها)

### Provider (المزود)
الشركة/الخدمة اللي تقدم الموديل: OpenAI، Anthropic، Google، Groq، Kiro…
أنواع الربط (من `docs/getting-started/PROVIDERS-GUIDE.md`):

| النوع | شنو يعني | أمثلة | الكلفة |
|------|---------|-------|--------|
| **Free** | ما يحتاج دفع | Kiro، OpenCode Free، Pollinations | $0 |
| **API Key** | تحتاج مفتاح من موقع المزود | OpenAI، Anthropic، Google، DeepSeek، Groq | حسب الاستخدام |
| **OAuth** | تسجل دخول بحسابك | Claude Code، GitHub Copilot، Codex | اشتراك |
| **Web Cookie** | يستخدم جلسة المتصفح | ChatGPT Web، Gemini Web | $0 (حسابك) |

### Connection (الاتصال / الحساب)
نفس المزود ممكن تضيفه أكثر من مرة (حسابين OpenAI مثلاً). كل واحد منهم "Connection" مستقل،
وOmniRoute يعامل كل حساب كمرشح منفصل (إذا واحد عليه rate limit يستخدم الثاني).

### Model ID (معرّف الموديل)
الصيغة: **`بادئة-المزود/اسم-الموديل`**. أمثلة حقيقية من التوثيق:

| المعرّف | المعنى |
|--------|-------|
| `cc/claude-opus-4-7` | `cc` = Claude Code (اشتراك OAuth) |
| `cx/gpt-5.5` | `cx` = Codex |
| `kr/qwen3-coder-next` | `kr` = Kiro |
| `if/kimi-k2.7-code` | `if` = Qoder |
| `glm/glm-4.7` | GLM |

> تكدر تشوف كل المعرفات المتاحة من صفحة **Model catalog** (`/dashboard/models`) أو من
> `GET /v1/models`.

### Combo (الكومبو)
**قائمة موديلات مرتبة باسم واحد** مع استراتيجية. ترسل `model: "اسم-الكومبو"` وOmniRoute
يجرب الأول، إذا فشل يروح للثاني… مثال:
```
Combo "premium-coding":
  1. cc/claude-opus-4-7    ← اشتراكك أولاً
  2. glm/glm-4.7           ← احتياطي رخيص
  3. if/kimi-k2.7-code     ← احتياطي مجاني
```

### Auto (التوجيه التلقائي)
بدل ما تختار موديل، تكتب `model: "auto"` وOmniRoute يقيّم كل المزودين المربوطين (الصحة، السرعة،
الكلفة، الجودة، الحصة) ويختار الأفضل. وعنده نسخ: `auto/coding`، `auto/fast`، `auto/cheap`،
`auto/smart`، `auto/offline`.

### API Key (مفتاح OmniRoute)
⚠️ **مو مفتاح OpenAI!** هذا مفتاح تصنعه داخل OmniRoute حتى أدواتك تدخل على OmniRoute.
مفاتيح المزودين الحقيقية تنحط بصفحة Providers، ومفاتيح OmniRoute تنعمل بصفحة API Keys.

### Endpoint (نقطة الاتصال)
الرابط اللي تحطه بأدواتك: `http://localhost:20128/v1`

## 🔁 مسار الطلب (شنو يصير لما ترسل رسالة)

من `AGENTS.md` بالمستودع، مبسّط:

```
أداتك ترسل طلب ← /v1/chat/completions
  ← التحقق من المفتاح والصلاحيات والسياسات
  ← حماية من حقن البرومبت (prompt injection guard)
  ← فحص الكاش ← حدود المعدل (rate limit)
  ← هل الموديل كومبو؟ → يحسب المرشحين ويجرب واحد واحد
  ← ضغط البرومبت (إذا مفعل)
  ← ترجمة الصيغة (OpenAI → Claude/Gemini...)
  ← إرسال للمزود + إعادة محاولة عند الفشل
  ← ترجمة الرد ورجوعه إلك (stream أو JSON)
  ← تسجيل الطلب (التوكنز، الكلفة، الوقت)
```

## 🧱 مكونات المشروع (إذا تحب تعرف شنو داخل المستودع)

| الطبقة | المكان | الوظيفة |
|-------|-------|--------|
| مسارات API | `src/app/api/v1/` | نقاط الدخول |
| المعالجات | `open-sse/handlers/` | معالجة الطلب (chat، embeddings…) |
| المنفذات | `open-sse/executors/` | إرسال الطلب لكل مزود |
| المترجمات | `open-sse/translator/` | تحويل الصيغ OpenAI↔Claude↔Gemini |
| الخدمات | `open-sse/services/` | الكومبو، حدود المعدل، الكاش |
| قاعدة البيانات | `src/lib/db/` | SQLite |
| سيرفر MCP | `open-sse/mcp-server/` | أدوات للوكلاء |
| سيرفر A2A | `src/lib/a2a/` | بروتوكول وكيل لوكيل |
| لوحة التحكم | `src/app/(dashboard)/` | الواجهة اللي راح تتعلمها |
